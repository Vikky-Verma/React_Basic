# Why react was created?
// => ghost message problem => incosistency in UI (facebook)
// does not sync state->js to UI-> dom
// => solution => virtual DOM (react) => sync state to virtual DOM and then to real DOM
// => react create virtual DOM and update it and then update real DOM
// => react create component and manage state and props


# Dont learn React if:
// => you are not comfortable with js
// you dont know how JS works or dom works
